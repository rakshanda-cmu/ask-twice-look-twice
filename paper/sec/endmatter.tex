\subsection*{Ethics statement}

This work studies prompt layout for existing, publicly released vision-language
models and introduces no new model, no new data collection and no human
subjects. All benchmarks used are public research datasets used for their stated
purpose. The intervention we study makes models more accurate without
fine-tuning, which lowers the compute cost of deployment but does nothing to
correct the biases those models already carry; a more accurate answer is not a
fairer one. RF20 includes surveillance-adjacent detection domains, and improving
presence detection there carries the usual dual-use risk of object detection
systems. We report the settings where our intervention fails, including video
and POPE, so that it is not applied where it does not help.

\subsection*{Reproducibility statement}

Every accuracy in this paper is read from a per-run result file recording the
model, ordering, system prompt, decoding budget and sample count.
Section~\ref{sec:setup} gives the models, benchmarks and protocol;
Appendix~\ref{app:repro} records the two configuration details that change the
result if missed, namely the knockout query scope and the exclusion of a
degenerate Gemma RF20 run. Code, the per-run result files and the figure
scripts, which regenerate every figure directly from those files, are provided
in the supplementary material, along with the prior workshop paper this work
extends. Significance tests use paired McNemar plus a paired bootstrap over
$5{,}000$ resamples with a fixed seed.
